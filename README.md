# Serega — онлайн 2D-шутер

## Содержимое
- `server.js` — Node.js HTTP + WebSocket сервер, комнаты, движение и попадания.
- `client.js` — игровой клиент, аватарки, настройки клавиш и выбор оружия.
- `index.html` — страница игры.
- `style.css` — стили интерфейса.
- `package.json` — зависимости и команда запуска.

## Запуск локально
Требуется Node.js 20+.

```bash
npm install
npm start
```

Затем откройте http://localhost:3000.

## Render
Build Command: `npm install`
Start Command: `npm start`
