# Serega — онлайн 2D-шутер

Комнаты создаются на сервере, игроки подключаются к общей комнате через ссылку `/?room=КОД`. Сервер обрабатывает движение, выстрелы, попадания, здоровье и возрождение. Это реальный WebSocket-мультиплеер, не локальная имитация.

## Требования
- Node.js 20+
- Доступный порт 3000

## Запуск на Windows
1. Установи Node.js 20 или новее с https://nodejs.org/
2. Открой PowerShell в папке проекта.
3. Выполни:
   ```powershell
   npm install
   npm start
   ```
4. Открой http://localhost:3000

## Игра с друзьями
- Для локальной проверки на одном компьютере можно открыть страницу в нескольких вкладках.
- Для друзей через интернет разверни приложение на сервере с публичным адресом и поддержкой WebSocket.
- Для HTTPS-сайта браузер автоматически подключается через WSS.
- После развёртывания укажи `PUBLIC_URL=https://твой-домен` (необязательно для клиентской ссылки; полезно для серверных ссылок).

## Управление
- WASD или стрелки — движение
- Мышь — прицел
- Левая кнопка мыши — стрелять
- Максимум 12 игроков в комнате; выстрелы обрабатываются сервером.

## Важно
Это рабочий прототип: нет аккаунтов, сохранения статистики между сессиями, античита промышленного уровня или TLS-сервера внутри Node. Публичный запуск рекомендуется за reverse proxy (например, Caddy/Nginx) с HTTPS/WSS и ограничением частоты подключений.
