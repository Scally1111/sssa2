# Serega — обновлённый проект

## Состав
- `server.js` — игровой сервер
- `client.js` — игровой клиент
- `index.html` — страница игры
- `style.css` — оформление
- `package.json` — зависимости и команда запуска

## Запуск локально
Требуется Node.js 20 или новее.

```bash
npm install
npm start
```

Затем откройте адрес, который выводит сервер в консоль (обычно `http://localhost:3000`).

## Обновление на Render
Загрузите файлы в корень GitHub-репозитория и подтвердите изменения. В Render используйте:
- Build Command: `npm install`
- Start Command: `npm start`

Аватарки и клавиши управления хранятся в браузере пользователя. Проверьте работу проекта после развёртывания.
